# Joloo (Backend & Frontend) 

Сервис поиска попутчиков (межрайонные поездки по Республике Бурятия). Проект разработан как полноценный командный кейс с акцентом на чистую архитектуру, асинхронный бэкенд на FastAPI и реактивный фронтенд на React + TypeScript.

## Стек технологий

### Backend (`app/`)
*   **Фреймворк:** FastAPI (Python 3.11+) — асинхронный, высокопроизводительный.
*   **База данных:** PostgreSQL 16.
*   **ORM:** SQLAlchemy 2.0 (Async Engine) + Alembic для миграций.
*   **Валидация данных:** Pydantic v2 + `pydantic-settings`.
*   **Аутентификация:** JWT (`PyJWT`) + `bcrypt`.
*   **Контейнеризация:** Docker + Docker Compose.

### Frontend (`frontend/`)
*   **Стек:** React 18 + TypeScript + Vite.
*   **Стилизация:** Tailwind CSS + Lucide Icons.
*   **Сетевой слой:** Axios (с перехватчиком JWT-токенов и Vite Proxy).
*   **Контракты API:** Документированы в [`docs/API_CONTRACT.md`](docs/API_CONTRACT.md).

## Быстрый запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/XRoyalPTX/joloo.git
cd joloo
```

### 2. Запуск через Docker Compose
Убедитесь, что у вас запущен Docker Desktop, и поднимите сервисы бэкенда и базы данных:
```bash
docker compose up -d
```
*   API Бэкенда доступно по адресу: `http://localhost:8000`
*   Интерактивный Swagger (Документация): `http://localhost:8000/docs`

### 3. Наполнение базы данных населёнными пунктами Бурятии
Чтобы в приложении сразу появились реальные районы, города и улусы для создания маршрутов, запустите скрипт импорта данных:
```bash
docker compose exec app python seed.py
# или локально: python seed.py
```
Скрипт автоматически отфильтрует и зальет в PostgreSQL 734 населенных пункта Республики Бурятия с привязкой к районам (аймакам) и типам поселений.

### 4. Запуск Frontend-клиента
```bash
cd frontend
npm install
npm run dev
```
*   Веб-интерфейс откроется по адресу: `http://localhost:5173`

## Структура базы данных 
### 1. Модель Location
*   `id`, `country`, `region`, `district`, `name`

### 2. Модель User
*   `id`, `name`, `surname`, `patronymic`, `birth_date`, `password`, `email`, `phone_number`, `is_active`, `is_staff`

### 3. Модель Trip
*   `id`, `driver_id`, `from_location_id`, `to_location_id`, `price`, `seats`, `departure_date`, `arrival_date`, `comment`

### 4. Модель TripRequest
*   `id`, `requester_id`, `trip_id`, `seats_requested`, `status` (`"pending"`, `"accepted"`, `"rejected"`, `"cancelled"`)
